commands to use and their functions:

node --print-bytecode
- Displays the raw, low-level bytecode generated by the 
  Ignition interpreter before the code is compiled to 
  machine code.

Pro-tip: Combine with node --print-bytecode --print-bytecode-filter=functionName 
so you only inspect the specific function rather than the whole script.

node --trace-opt 
- What it does: Prints a real-time log whenever 
V8's TurboFan compiler optimizes a function into 
native machine code.

Output indicator: Look for markers like 
[marking ... for optimization] or 
[compiling method ... (turbofan)].

node --trace-deopt
- Prints a notification whenever V8 is forced to throw away 
  optimized machine code and drop back down to bytecode.

Output indicator: Displays the line number, function name,
  and reason (such as insufficient type feedback 
  or not a Smi / Small Integer).
